# NewsBot Intelligence System 2.0

Advanced NLP news-analysis platform (ITAI 2373 Final Project, Trilok Kalani).
This Space wraps the project's `src/` package in a Gradio interface: classify an
article, ask questions in plain English, search by meaning, and view discovered
topics. On first boot it clones the source repository and trains the lightweight
components once.

Source: https://github.com/Tikskalani/ITAI2373-Portfolio
