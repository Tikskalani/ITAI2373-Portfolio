# Individual Contributions

This is a solo (SOLO group) submission. Trilok Kalani completed all work.

- Architecture and refactor: designed the modular `src/` package and ported the
  midterm notebook pipeline into clean, single-responsibility classes.
- Module A (advanced content analysis): classifier with confidence and an
  uncertainty guard, sentiment and emotion, domain-aware NER, and LDA plus NMF
  topic modeling.
- Module B (language understanding and generation): extractive summarization with
  an optional transformer path, TF-IDF and optional SBERT semantic search, content
  enhancement, and WordNet query expansion.
- Module C (multilingual): language detection, translation, and analyze-in-English.
- Module D (conversational): intent detection, query routing, response generation.
- Web application (bonus): the Flask dashboard, templates, and static assets.
- Testing and docs: the pytest suite, this documentation set, and the written
  deliverables.

AI-use disclosure: I used an AI assistant for code implementation, refactoring,
debugging, and drafting. I chose the architecture and methods, ran and reviewed the
code, verified the outputs, and am responsible for the design and interpretation.
